# Evidence gap analysis

Work only on the assigned task slice.

1. List what the task still cannot support with snapshot-backed evidence.
2. Prefer independent sources over restating the same page.
3. Do not invent quotes, claims, or approvals.
4. Do not request extra tools, budget, or workers.
5. Return gaps as notes with artifact refs when they exist.
