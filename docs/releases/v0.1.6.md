# DeepScout v0.1.6

DeepScout v0.1.6 is a backward-compatible public-demo and documentation hotfix.

## Fixed

- Anonymous visitors can open a published run's plan without a client-side exception.
  The public workspace intentionally omits internal task tool assignments; the frontend now
  models those fields as optional and renders only fields present in the public projection.
- Public report pages no longer present Markdown/PDF export links that the server correctly
  reserves for owners. Copying the rendered report remains available.
- The root README, changelog, project specification, environment guide, architecture overview,
  local-development guide, deployment guide, Docker guide, agent-runtime guide, release Compose
  defaults, package metadata, and outbound source-fabric user agent now identify the current
  release consistently.
- Detailed architecture and operations references now match the implemented monorepo paths,
  Alembic head `017`, Node.js 22 LTS, 70-slot evaluator registry, corroborated claim semantics,
  secure fetch pipeline, and bounded/revalidated SSE behavior.

## Security posture

- Public demos remain read-only and do not gain access to omitted task internals.
- Private workspaces continue to display task tool assignments when present.
- The v0.1.5 security controls and supply-chain gates remain unchanged.

## Upgrade

The database head remains Alembic `017`; no migration is required from v0.1.5.

The public images are:

```text
ghcr.io/francescoveryra-dot/deepscout-api:0.1.6
ghcr.io/francescoveryra-dot/deepscout-web:0.1.6
```
