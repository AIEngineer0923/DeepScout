# DeepScout v0.1.5

DeepScout v0.1.5 is a backward-compatible security hardening release.

## Security fixes

- OAuth state is bound to the browser that initiated login, preventing login-CSRF and
  account session swapping.
- Public demos expose only sanitized presentation endpoints. Raw events, reviews, exports,
  source preferences, evaluations, and knowledge internals remain owner-only.
- Hosted LangSmith credentials are installed per run and removed afterward; maintainer
  environment keys are not a worker-wide tracing baseline.
- HITL review resolution and creation use database row locks, so concurrent decisions
  cannot apply budget extensions or resume work more than once.
- SSE streams revalidate hosted sessions while open and replay events in bounded batches.
- Hosted run and monitor quotas are principal-scoped and serialized with PostgreSQL
  advisory transaction locks.
- Research budgets have hard upper bounds and enforce actual elapsed wall time.
- Quote presence now establishes provenance only; full verification requires distinct-source
  corroboration.
- PDF parsing runs in a bounded subprocess, MIME admission is allowlisted, and multilingual
  prompt-injection markers are excluded from model context.
- Rate limiting always enforces a client-address bucket; rotating arbitrary session-cookie
  values cannot bypass mutation limits or allocate attacker-chosen identities.
- Redirect and Markdown URL handling reject protocol-relative, backslash, and control-character
  variants.

## Supply-chain hardening

- The API image moved from Debian slim to pinned Python 3.12 Alpine, removing the vulnerable
  unused Perl runtime from the image.
- Release application containers run read-only with all Linux capabilities dropped and
  `no-new-privileges`.
- Release publication now blocks on HIGH/CRITICAL image scanning and publishes GitHub artifact
  attestations in addition to OCI SBOM and BuildKit provenance.
- Python workspace and frontend lockfiles now consistently declare `0.1.5`.

## Upgrade

The database head remains Alembic `017`; no new migration is required from v0.1.4.

The public images are:

```text
ghcr.io/francescoveryra-dot/deepscout-api:0.1.5
ghcr.io/francescoveryra-dot/deepscout-web:0.1.5
```
