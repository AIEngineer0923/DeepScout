# DeepScout v0.1.2

DeepScout v0.1.2 is a focused routing and research-entry parity patch discovered during the hosted
multi-domain regression matrix for v0.1.1.

## Reliability patch

- A generic mention of an API no longer implies that repository search is relevant.
- GitHub and technical-documentation discovery still activates for explicit software, SDK,
  repository, package, library, framework, or open-source intent.
- The Dashboard composer and the sidebar **New Research** screen share one create-and-execute path,
  including the same automatic geographic, freshness, model, and domain-exclusion defaults.
- Both entry points preserve the chosen Quick, Standard, or Deep mode and report language.
- Launch failures are surfaced on the Dashboard instead of becoming an unhandled client promise.

## Compatibility

- Database schema remains Alembic head `016`; no migration is required.
- MODE A local and MODE B hosted deployment contracts are unchanged.
- Public demos remain read-only and cannot spend provider budget.

- `ghcr.io/francescoveryra-dot/deepscout-api:0.1.2`

release commit SHA.
