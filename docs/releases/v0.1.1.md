# DeepScout v0.1.1

DeepScout v0.1.1 is a reliability patch based on forensic analysis of a real hosted run that
returned search candidates but admitted no relevant sources.

## Reliability closure

- Subject-preserving, bounded query reformulation across research domains.
- Truthful task outcomes: zero admissible sources is blocked, never completed.
- Dependency-block propagation and explicit checkpoint outcomes.
- Evidence-aware run outcomes, distinct SSE terminal events, and localized UI explanations.
- Evaluation and continuous-learning consistency for zero-progress trajectories.
- Contract schema v2 numeric constraints, conflict disclosure, and deterministic allocation sums.
- Capability-aware discovery router with indexed-web fallback, OpenAlex scholarly search, and public
  GitHub repository/README discovery.
- Goal-conditioned multi-source portfolios: independent publisher families, source-kind diversity,
  materially different query families, and saturation-aware stopping.
- Secure normalization for HTML, text, JSON, XML, RSS/Atom, PDF, and accessible public video metadata
  or captions with provenance.
- Source-aware UI and deterministic evaluations for diversity, independence, fetch success,
  original citations, publisher duplication, source-type compliance, freshness, contradiction
  resolution, and corroboration.
- Bounded public connector responses and XML/PDF/video normalization continue through the existing
  SSRF, redirect, untrusted-content, tenant, and BYOK boundaries.

## Compatibility

- Database schema remains Alembic head `016`; no migration is required.
- MODE A local and MODE B hosted deployment contracts are unchanged.
- Public demos remain read-only and cannot spend provider budget.
