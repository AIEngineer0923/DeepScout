# DeepScout v0.1.7

DeepScout v0.1.7 is a backward-compatible frontend security patch.

## Security

- Next.js is `15.5.25`, which includes the v15.5.24 fixes for unauthenticated RCE on
  Windows-hosted servers and in the image-optimization API when AVIF is used.
- `sharp` is pinned to `0.35.4` so the bundled libheif advisories do not remain in the web image.
- Transitive `js-yaml` is pinned to `4.3.2` so merge-key CPU exhaustion is not reachable from
  ESLint tooling.
- Vitest and `@vitest/mocker` are `4.1.11`, which closes redirect-mock path traversal without
  taking the breaking Vitest 5 line.

## Changed

- `npm run lint` uses the ESLint CLI with a Next.js-compatible flat config. Next.js 15.5 no longer
  prompts interactively to bootstrap ESLint.

## Upgrade

The database head remains Alembic `017`; no migration is required from v0.1.6.

The public images are:

```text
ghcr.io/francescoveryra-dot/deepscout-api:0.1.7
ghcr.io/francescoveryra-dot/deepscout-web:0.1.7
```
