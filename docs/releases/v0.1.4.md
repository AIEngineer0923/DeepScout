# DeepScout v0.1.4

DeepScout v0.1.4 is a content-acquisition hotfix following the v0.1.3 answerability release.

## Fixed

- The deterministic HTML parser no longer stops after a page `<title>` when the real content
  follows in `<body>`, `<main>`, or `<article>`.
- Sphinx-style official documentation pages now produce full, provenance-preserving snapshots
  instead of being rejected as low-value title-only content.
- Script, style, navigation, header, footer, and embedded content remain excluded from snapshots.
- Explanatory technical requests containing “build requirements” remain narrative instead of
  being mistaken for a request to build an entity list.
- Native multilingual searches preserve official-documentation preferences, including common
  Italian, French, German, and Spanish formulations.
- A single-language Quick run now uses one precise native query and one relaxed deterministic
  fallback, preventing duplicate over-constrained variants from exhausting the discovery budget.

## Upgrade

The database head remains Alembic `017`; no new migration is required from v0.1.3.
