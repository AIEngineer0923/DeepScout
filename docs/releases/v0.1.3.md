# DeepScout v0.1.3

DeepScout v0.1.3 closes the general answerability gap for large entity, comparison, ranking,
allocation, and constrained-selection research. It does not promise that inaccessible or
non-existent public information can always be verified; it ensures that ordinary answerable tasks
produce the requested useful deliverable while sparse fields remain explicitly uncertain.

## Highlights

- Contract schema v3 and generic deliverable classification.
- Persisted entity/attribute evidence matrix and complete research-yield funnel.
- Attribute-aware multi-query extraction and progressive narrowing.
- Deterministic exact-count, quota, budget, include/exclude, and comparison validation.
- Answer-first reports with responsive Markdown tables.
- One-task Quick path, explicit follow-up lineage/context reuse, and human-input HITL resolution.
- Goal-conditioned native-language query plans with separate user, output, query, and source
  languages; immutable original-language evidence and visible provenance.
- Cross-language dense retrieval with intent-aware RRF/reranking plus a reproducible seven-pair
  multilingual ablation benchmark.
- Deterministic multilingual evaluators and learning failure classes without adding a translation
  service or changing the validated embedding space.

## Upgrade

This release requires Alembic head `017`:

```bash
cd libs/persistence
uv run alembic upgrade head
```

The public images are:

```text
ghcr.io/francescoveryra-dot/deepscout-api:0.1.3
ghcr.io/francescoveryra-dot/deepscout-web:0.1.3
```

API and worker use the API image with their respective process roles. Run the one-shot migration
role before starting either persistent process.
